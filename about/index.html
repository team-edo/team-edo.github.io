Team Edo는 국악기 입문자가 혼자서도 연습을 이어갈 수 있도록 ‘얼쑤’를 만드는 팀입니다.

Edo는 세종대왕의 이름 ‘이도’에서 따왔습니다.

팀원 소개

얼쑤를 만드는 사람들

앱 화면을 설계하는 일부터 연주를 분석하고 서비스를 운영하는 일까지, 팀원마다 맡은 일을 소개합니다.

FRONTEND · UI

송가연

다음에 무엇을 할지 보이는 화면을 설계합니다.

악기를 고르는 첫 화면부터 평가 결과까지, 필요한 정보와 조작이 한눈에 들어오도록 배치합니다. 글씨를 키웠을 때도 연습을 이어갈 수 있는지 살핍니다.

FRONTEND · UX

권영민

정간보에서 실제 연습으로 이어지는 길을 만듭니다.

정간보를 읽던 사용자가 연습을 시작하고, 연주를 마치면 평가를 확인할 수 있도록 앱의 동작을 구현합니다. 각 화면에 필요한 서버 요청과 응답을 연결합니다.

BACKEND · BLOG

오은서

로그인과 연습에 필요한 서버 기능을 만듭니다.

회원 인증과 연습·평가 요청을 처리하는 API를 개발합니다. 팀이 개발 경험을 공유할 수 있도록 블로그 화면과 글을 게시하는 절차도 다듬습니다.

DATA · BACKEND

박찬형

국악 음원과 악보를 앱에서 쓸 수 있게 합니다.

음원과 악보를 정리하고 서비스에서 읽을 수 있는 형식으로 변환해 검증합니다. 곡·악보 조회, 평가 연동과 회원 탈퇴에 필요한 서버 기능을 구현합니다.

AI · DATA

사지한

녹음 속 음을 정간보와 맞춰 봅니다.

연주 녹음에서 음높이를 찾아 악보의 음과 비교합니다. 어떤 음을 맞히고 놓쳤는지 판별하는 기준을 만들고, 평가 데이터와 검증 도구로 채점 결과를 점검합니다.

INFRA · SECURITY · BACKEND

우동균

서비스를 배포하고 지키는 환경을 만듭니다.

빌드와 배포를 자동화하고 접근 권한과 백업·복구 절차를 정비합니다. 서버 기능이 실제 앱에서도 동작하는지 확인하고, 반복되는 개발 작업은 팀이 함께 쓸 도구로 만듭니다.

HOW WE WORK
